# Automated UX QA checklist

> A skill for running automated UX quality checks against design and copy standards.

**Type:** Skill
**Author:** Sophie Felder
**Link:** [→ View on GitHub](https://github.com/canonical/automated-ux-qa-checklist-and-quality-standards/tree/main/copy-doc-review)

---

## What it does

Automates parts of the UX QA process by checking designs and copy documents against a defined set of quality standards. Catches common issues like inconsistent terminology, missing error states, and copy that doesn't follow guidelines.

## When to use it

Use this when you're reviewing a design or copy doc before handoff. It catches the mechanical things so you can focus your review time on the harder judgment calls.

## How to use it

1. See the repo link above for setup and usage instructions
2. Point the skill at your copy doc or design
3. Review the flagged issues
