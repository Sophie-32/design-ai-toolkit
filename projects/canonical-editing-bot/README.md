# Canonical editing bot

> A Gemini gem for editing and reviewing UX copy against Canonical guidelines.

**Type:** Gem
**Author:** Sophie Felder
**Link:** [→ Use this gem](https://gemini.google.com/gem/1by40MgpqziudIag_kDudqX5A3IyeySEi?usp=sharing)

---

## What it does

Companion to the UX writing bot. Paste in existing copy and this gem reviews it for voice, tone, clarity, and consistency with Canonical guidelines. It flags issues and suggests improvements.

## When to use it

Use this when you have draft copy and want a quick review before sharing with the team. Works well as a second pair of eyes on error messages, notifications, and longer-form UI text.

## How to use it

1. Open the gem link above in Gemini
2. Paste in the copy you want reviewed
3. The gem returns feedback and suggested edits
4. Apply the suggestions that make sense for your context
