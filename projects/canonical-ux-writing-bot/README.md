# Canonical UX writing bot

> A Gemini gem that writes UX copy in the Canonical voice and tone.

**Type:** Gem
**Author:** Sophie Felder
**Link:** [→ Use this gem](https://gemini.google.com/gem/11cj7WLvoFIT5GbxfIAvcX5eufpgYN0uv?usp=sharing)

---

## What it does

A Gemini gem configured to generate UX copy — button labels, error messages, tooltips, onboarding text — that follows Canonical's voice and tone guidelines. Give it context about what you're designing and it returns draft copy you can use directly or refine.

## When to use it

Use this when you're writing interface copy and want a starting point that already sounds like Canonical. Particularly useful for first drafts, generating multiple options, or checking whether your copy follows the voice guidelines.

## How to use it

1. Open the gem link above in Gemini
2. Describe the UI context (what screen, what the user is doing, what action they're taking)
3. The gem returns copy options in the Canonical voice
4. Refine and adapt the output for your specific context
