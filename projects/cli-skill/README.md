**Type:** Skill
**Author:** Hartmut Obendorf
**Link:** [→ View on GitHub](https://github.com/canonical/cli-skill)

## What it does

A Copilot skill that helps review CLI designs and implementations against Canonical CLI guidelines. It can evaluate command structures, flag inconsistencies, and suggest improvements to make CLIs more user-friendly.

## When to use it

Use this when you're designing or reviewing a CLI tool and want to check it follows Canonical conventions for command naming, help text, output formatting, and error handling.

## How to use it

1. Install the skill in your VS Code Copilot setup (see repo for instructions)
2. Invoke the skill when reviewing CLI code or designs
3. It provides feedback based on Canonical CLI standards
